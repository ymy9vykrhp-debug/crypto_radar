# Компактный Crypto Radar

Проверенный запуск: откройте START_LOCAL.cmd и оставьте окно работающим.
После сообщения о готовности откройте http://127.0.0.1:51875 в Chrome.
Либо выполните в этой папке:

```powershell
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 51875
```

Если программа уже запущена на этом порту, используйте её открытое окно.
Для следующего запуска сначала завершите прежний запуск клавишей q в его терминале.

START_CHROME.cmd оставлен как стандартный вариант Flutter. На этом ноутбуке
его последняя проверка завершилась тайм-аутом подключения отладчика Chrome;
локальный веб-сервер успешно работает без этого подключения.

## Что изменено

- Сводка и управление сверху; график слева, итоговое решение и уровни справа на широком экране. На узком экране — одна колонка.
- Таблица ENTRY, STOP, TAKE и состояния выхода. LONG зелёный, SHORT красный, отсутствие активного сетапа серое. Цвет не является разрешением входа.
- LIVE отключает WebSocket и автоматические REST-запросы. Начатые запросы могут завершиться. Проверка возраста данных продолжается; ручное обновление доступно.
- Переключатели «График», «3 мозга», «Подробности» управляют видимостью. Каждый блок объяснений раскрывается отдельно.
- «Три мозга» объясняют структуру, контекст и риск по существующим расчётам. «Главный» показывает реальные причины итогового состояния. Это не независимые AI-агенты и не платные API-вызовы.
- Для открытой ручной позиции таблица показывает её фактический вход, текущий стоп и сохранённые цели.
